# @deepseek-ai/dsh-client-ui-usage

[English](README.md) | 中文

Web 设置中的只读**用量统计**页面。浏览器插件在页面挂载时按需请求 `session.list`，把每一行的 `usageStats` 投影折叠为一个总览，并在页面打开期间每分钟刷新一次。页面展示累计与峰值 token、最长聊天跨度、活动连续天数、每日/每周/累计活动、工具与技能调用，以及最常用模型和推理强度。注册使用 `ctx.slots.inject('settings.section', ...)`，因此会跟随延迟声明、重新声明、语言变化与卸载。

Host 所有的 `usageStats` 值来自 [`@deepseek-ai/dsh-session-stats`](../../session/session-stats/README.md) 的全日志投影。同一步骤的提供方用量样本以后者替换前者；输入量包含未缓存、缓存读取和缓存写入 token；工具调用按日志中的工具名分组；`skill` 调用还会解析日志中的技能名。模型与推理强度统计的是活动请求头下进入的步骤。所有聚合只发生在本机 Host 与浏览器内；本包不会把用量、会话、凭据或工作区数据发送给其他服务。

## 模型体验

无，因为本包只在浏览器设置中渲染 Host 投影的用量，不注册任何面向模型的能力。

#### KV Cache 影响

无；页面只读取已有会话摘要，从不组装或发送提供方请求。

## 已知局限与延后工作

- **冷会话的检查点新鲜度**——未挂载会话行提供最近一次持久投影检查点；在该会话再次挂载并写入检查点前，它可能落后于日志尾部，`asOfSeq` 保留这一陈旧边界。
- **只统计数量，不计算金额**——页面不会根据模型名推断价格或估算计费货币金额。
- **Host 本地日历日**——每日分桶使用日志回放时 Host 的时区；把同一份日志移到另一时区的 Host 后，午夜附近的事件可能落入不同日期。
